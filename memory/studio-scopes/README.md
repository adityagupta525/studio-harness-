# studio-scopes

Approved facts about **the studio itself**: positioning, locked looks, bibles for the studio's own work.

Until the owner decides them, the studio's name, story, logo, identity and positioning are **not decided**. Nothing here may state otherwise. A studio scope is written only in a `studio` context session, from the owner's explicit pick, with the owner's exact words and date.

Each scope file carries a `review_by` date. Nothing from `client:<name>` or `employer` contexts enters this folder.

No studio scopes exist yet.
